# 📊 Power BI Sales Analysis Dashboard

## 📌 Overview

This project is an interactive **Sales Analysis Dashboard built using Microsoft Power BI**. The project focuses on transforming raw Excel data, performing data cleaning and modeling, creating DAX calculations, and developing interactive visualizations to generate meaningful business insights.

The dashboard provides insights into **sales, profit, quantity sold, discounts, orders, products, customers, promotions, and geographical sales performance**.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Microsoft Excel**
- **Data Cleaning & Transformation**
- **Data Modeling**
- **Data Visualization**

---

## 🔄 Data Preparation & Transformation

The raw data was imported from **Excel** and prepared using Power Query.

Key transformation steps included:

- Imported data from Excel.
- Cleaned and transformed raw datasets.
- Corrected inappropriate **data types**.
- Handled and replaced **null/missing values**.
- Created new columns during transformation.
- Performed **joins/merges between multiple tables**.
- Prepared the transformed data for analysis and visualization.

---

## 📈 Dashboard & Visualizations

The transformed data was used to create an interactive Power BI dashboard containing:

- 📊 **Bar Charts**

## 💡 Key Business Insights

The dashboard was designed to answer the following business questions:

### 1. Top & Bottom Products
- Identify the **Top 5 and Bottom 5 products** based on:
  - Sales
  - Profit
  - Quantity Sold

### 2. Sales Trends
Analyze how sales vary over different time periods:

- Daily
- Monthly
- Quarterly
- Annually

### 3. Sales & Profit Relationship
Analyze the relationship between **Sales and Profit** using visual analytics.

### 4. Period Comparison
Compare the following metrics between **two user-selected time periods**:

- Sales
- Profit
- Quantity Sold

### 5. Discount Analysis
Analyze the **average discount offered across different discount categories**.

### 6. Order Analysis
Track the **total number of orders** and analyze order-level performance.

### 7. Detailed Order Analysis
View order-level information including:

- Sales
- Profit
- Discount
- Net Sales
- Product
- Date
- Customer ID
- Promotion Category
- Other relevant order fields

The data can be dynamically filtered using Power BI's visual filters and slicers.

### 8. Geographical Sales Analysis
Analyze **sales performance across different cities** using map visualizations.
